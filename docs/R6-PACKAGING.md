# R6 — поставка

28 октября 2026. **Сделан пакет `.deb`**, проверен на Debian 13 и Ubuntu 24.04
(основа Linux Mint 22). **Обновляльщик ещё не сделан** — см. «Что дальше».

## Пакет

Сборка: `packaging/build-deb.sh --version 0.1.0` → `artifacts/EliteRec-0.1.0.deb`
(36 МБ, распакованный 114 МБ). Устроен как пакет EliteSIP для Linux
(`Linux EliteSip/tools/build-deb.sh`) — те же пути и правила.

| Путь | Что |
|---|---|
| `/opt/eliterec/EliteRec` | программа с рантаймом .NET (self-contained, ReadyToRun) |
| `/usr/share/applications/eliterec.desktop` | ярлык в меню («Запись звонков») |
| `/etc/xdg/autostart/eliterec.desktop` | автозапуск в трей (`--tray`); менеджер выключает у себя |
| `/usr/share/icons/hicolor/{16…512}/apps/eliterec.png` | значок |
| `/usr/share/doc/eliterec/` | copyright, changelog с коммитом сборки |

- **Самодостаточная публикация:** ни в EliteLinux, ни в Mint .NET не стоит.
  ReadyToRun сокращает JIT при запуске — окно появляется за 0,77 с на SSD
  (на HDD дольше; на A6 не замерено).
- **Зависимости с альтернативами** под обе системы — урок EliteSIP, у которого
  одна жёсткая `libicu74` сломала установку на Debian 13:
  `libicu76 | libicu74 | libicu72`, `libflac14 | libflac12t64 | libflac12`; плюс
  libpulse0, libmp3lame0, libopus0, X11-библиотеки Avalonia, fontconfig,
  xdg-utils. Рекомендуются `pipewire-bin | pulseaudio-utils` («Прослушать» в
  самопроверке) и `libgl1` (отрисовка через видеокарту).
- **Автозапуск** — сразу в трей: окно не появляется при каждом входе в систему.
  Если панель не показывает трей, окно сворачивается в панель задач.
- **Второй запуск** (ярлык при работающем автозапуске) показывает окно первого.
- Скриптов установки нет: значки и ярлыки подхватывают триггеры dpkg
  (hicolor, desktop-file-utils). Удаление убирает всё, кроме записей и
  настроек менеджера в его профиле.
- `EliteRec --check-codecs` — диагностика установки: секунда тишины в каждом
  формате; код 0 — все форматы пишутся.

## Проверки

| Проверка | Результат |
|---|---|
| `apt install ./EliteRec-0.1.0.deb` в чистом `debian:trixie` | зависимости найдены, MP3/FLAC/Opus/WAV — ok |
| то же в чистом `ubuntu:24.04` (основа Mint 22) | то же |
| `apt remove eliterec` | `/opt/eliterec` и автозапуск удалены |
| Программа из пакета на Mint 22.3 без установленного .NET | окно за 0,77 с, 2,6 % ядра, 190 МБ |
| CI (GitHub Actions) | пакет собирается и ставится на обе системы на каждом коммите (jobs `package`, `install`) |

Не проверено: установка в самом EliteLinux (нужен `sudo`), запуск на A6 с HDD,
автозапуск в трей после настоящего входа в систему.

## Что дальше: обновляльщик

По плану — как у EliteSIP: root-служба `eliterec-updater` по таймеру читает
подписанный Ed25519 манифест на `update.elitesip.vip`, сверяет SHA-256 и
ставит пакет через `apt-get`. Для этого нужно:

1. **Своя пара ключей подписи** выпусков EliteRec (закрытый ключ хранит тот,
   кто выпускает; открытый — в пакете).
2. **Правка сервера `elitesip_update`:** сейчас он отдаёт только
   `releases/linux/` EliteSIP — нужен каталог EliteRec.
3. **Правило «не обновлять во время записи»:** перезапуск посреди звонка
   недопустим — обновление ставится, только когда запись не идёт.
