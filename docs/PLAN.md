# План EliteRec для Linux

Составлен 26 октября 2026 по итогам обсуждения требований. Документ написан так,
чтобы работу можно было начать и продолжить без истории переписки.

EliteRec — программа записи звука видеопрезентаций (Zoom, Яндекс Телемост):
одновременно пишет микрофон менеджера и звук системы, где слышен клиент.
Linux-версия — первая; она нужна для EliteLinux (корпоративный дистрибутив на
Debian 13 + Xfce, `/media/koreva/EliteDev/EliteLinux`).

## Решения

| Вопрос | Решение |
|---|---|
| Что пишем | Звук: микрофон + звук системы (то, что слышит менеджер). Экран не пишем |
| Запуск записи | Только вручную. Автозаписи нет, всем управляет менеджер |
| Файлы | Один файл на запись — **стерео**: слева микрофон (менеджер), справа система (клиент); его отправляют на расшифровку и его же можно слушать. По желанию в настройках — ещё **общий микс** в моно (решение 28 октября 2026; было — всегда два файла) |
| Формат по умолчанию | MP3. Стерео 192 кбит/с **без joint stereo** (иначе каналы частично смешиваются); моно-микс, если включён, — 128 кбит/с. В настройках — MP3, FLAC, Opus, WAV |
| Расшифровка | Yandex SpeechKit, Whisper, Vox; чаще Whisper, модели меняются. Раздельные каналы нужны, чтобы перестроить расшифровку «менеджер / клиент» |
| Где хранить | Локально. Папка по умолчанию — «Записи EliteRec» на рабочем столе. В Битрикс записи загружает сам менеджер |
| Имя файла | `2026-10-26_14-30_<название>.mp3` (стерео) и, если включён, `…_mono.mp3`; название вводится после «Стоп», необязательно |
| Сбои | Запись пишется на диск частями по ходу; после падения программы или ПК при следующем запуске — предложение восстановить. Подвисание системы или потеря звука запись не обрывают: на месте пропуска тишина и строка в файле событий |
| Целевые ПК | EliteLinux (Debian 13) и Linux Mint 22, в том числе слабые (A6 / 4 ГБ / HDD) с Телемостом, камерой, мессенджером и браузером параллельно: нагрузка записи — единицы процентов ядра |
| Уведомление | При старте записи — «Идёт запись — предупредите клиента» |
| Интерфейс | Полноценное окно: выбор устройств, настройки, «Запись / Пауза / Стоп», таймер, индикаторы уровня микрофона и системы. Значок в трее. Горячей клавиши нет (решение 28 октября 2026) |
| Язык | Русский; строки — в ресурсах, чтобы добавить другие языки |
| Телефонные звонки | Не пишем — их пишет Asterisk (FreePBX) |
| Кодеки | Системные библиотеки через P/Invoke: libmp3lame, libFLAC, libopus. Без встроенного ffmpeg (+80 МБ) |
| Обновления | Как у EliteSIP: свой обновляльщик, отдельный канал на `update.elitesip.vip` |
| Стек | Как у EliteSIP: C#/.NET 10, Avalonia 12. Linux и Windows — общий код, разные аудиодрайверы. macOS — отдельно на Swift |
| Будущее | Загрузка записей в Битрикс через вебхук (не в первой версии) |

## Устройства — главное требование

Нынешняя сторонняя программа постоянно сбрасывает выбранные устройства. Обычные
причины: устройство запоминается **по номеру в списке** (номера меняются при
переподключении и перезагрузке) или программа каждый раз берёт **системное
умолчание**. В EliteRec:

1. **Устройство запоминается по постоянному идентификатору** — имени узла
   PipeWire/Pulse (`node.name` / `device.name`), а не по номеру и не по
   отображаемому имени.
2. **«Системный» — отдельный явный выбор**: «следовать умолчанию системы»
   (умолчание PipeWire). Конкретное выбранное устройство никогда не подменяется
   умолчанием.
3. **Слежение за подключением/отключением**: выбор восстанавливается, когда
   устройство возвращается.
4. **Пропажа устройства во время записи** (выдернули гарнитуру): запись не
   останавливается и продолжается с системного устройства; менеджер видит
   предупреждение «Микрофон отключён, пишем с системного». Когда устройство
   возвращается — запись переключается обратно, в файле остаётся отметка времени
   каждого переключения (`имя_события.txt` рядом с записью, см. R4-DEVICES.md).
5. **Звук системы** берётся с монитора выбранного вывода (`<sink>.monitor`), а
   при «Системном» — с монитора текущего вывода по умолчанию, и следует за ним,
   если умолчание сменилось во время записи (наушники ↔ динамики).

В EliteSIP это уже решено для звонков — переиспользуем (копируем и адаптируем,
не выносим в общую библиотеку). Исходники — `Linux EliteSip` на диске EliteDev1:

- `src/EliteSIP.Audio.Pulse/PulseDeviceWatch.cs` — слежение сравнением снимков,
  язык `AudioDeviceChange`;
- `src/EliteSIP.Audio.Pulse/PulseDeviceRules.cs` — чистые правила «свойства
  устройства → решение» (с тестами);
- `src/EliteSIP.Audio.Pulse/PulseDeviceCatalog.cs`, `Native/LibPulse.cs` —
  перечисление устройств и обёртка libpulse.

## Устройство репозиториев

По образцу EliteSIP (`Linux EliteSip`, `Win EliteSIP`, `Swift EliteSIP`).
Временно репозитории живут на диске EliteDev (`/media/koreva/EliteDev/projects/`),
потому что EliteDev1 смонтирован только для чтения; перенести к проектам EliteSIP,
когда диск будет доступен на запись.

```
projects/
  EliteRec Linux/      ← этот репозиторий, начинаем с него
    shared/            ← общий код Linux и Windows (позже — подмодуль, как в EliteSIP)
    src/
    tests/
    packaging/         ← .deb для EliteLinux
    docs/
  EliteRec Win/        ← позже
  EliteRec Swift/      ← позже, macOS (ScreenCaptureKit, macOS 13+)
```

Проекты (предварительно):

| Проект | Платформа | Что внутри |
|---|---|---|
| `EliteRec.Core` | net10.0, общий | Модель записи (состояния, пауза, отметки переключений), микширование и разведение каналов, нарезка частей и восстановление, настройки, имена файлов |
| `EliteRec.Encoding` | net10.0, общий | P/Invoke к libmp3lame / libFLAC / libopus, запись WAV; потоковое кодирование частей |
| `EliteRec.Audio.Pulse` | Linux | Захват микрофона и монитора вывода через libpulse (работает и на PipeWire через `pipewire-pulse`), слежение за устройствами |
| `EliteRec.Audio.Wasapi` | Windows (позже) | Захват микрофона и WASAPI loopback |
| `EliteRec.App` | Avalonia | Окно, трей, уведомления, диалог названия, настройки, восстановление |
| `EliteRec.Updater.Linux` | Linux | Обновляльщик от root по таймеру systemd — как у EliteSIP |

## Звуковой тракт (Linux)

```
микрофон (Pulse source) ─────► буфер mic ─┐
                                           ├─► выравнивание ─┬─► L=mic, R=sys ─► кодер ─► части .mp3
монитор вывода (sink.monitor) ► буфер sys ─┘   по времени    └─► микс (моно)   ─► кодер ─► части _mono.mp3 (по желанию)
```

- Оба потока — 48 кГц, float32, моно (монитор сводится в моно).
- Потоки приходят независимо — нужна синхронизация по меткам времени и
  компенсация дрейфа (разные часы устройств), иначе за час менеджер и клиент
  разъедутся на секунды. Решение и замеры — отдельным документом этапа R2.
- Пауза: оба потока продолжают читаться, но не пишутся — без щелчков на стыках.
- Микс: сумма с ограничителем (без клиппинга), уровни выравниваются настройкой
  «громкость микрофона / системы» (по умолчанию 1:1).

## Этапы

| Код | Что | Готово, когда |
|---|---|---|
| **R0** | Риски: замеры на машине разработки и на эталонном слабом ПК (A6, 4 ГБ, HDD): захват монитора на PipeWire, дрейф часов за час, нагрузка кодирования MP3 двух потоков, поведение при выдёргивании USB-гарнитуры | `docs/R0-RISKS.md` с цифрами |
| **R1** | Каркас: решение, проекты, CI-сборка, перенос аудиокаталога и слежения из EliteSIP с тестами | собирается, тесты зелёные |
| **R2** | Захват и тракт: два потока, синхронизация, микс и стерео, WAV на выходе | 60-минутная запись без рассинхрона больше 50 мс |
| **R3** | Кодирование и части: MP3/FLAC/Opus/WAV, запись частями, сборка итоговых файлов, восстановление после падения | `kill -9` посреди записи → запись восстанавливается |
| **R4** | Устройства: выбор по постоянному ID, «Системный», восстановление выбора, переключение при пропаже во время записи с отметками | сценарии из раздела «Устройства» проходят на реальной гарнитуре |
| **R5** | Интерфейс: окно, индикаторы уровня, трей, уведомление о старте, диалог названия, настройки | менеджер проходит запись без подсказок |
| **R6** | Поставка: .deb (зависимости — под Debian 13, не Ubuntu: урок EliteSIP с `libicu74`), обновляльщик, канал на `update.elitesip.vip` | ставится в EliteLinux и обновляется |
| **R7** | Пилот на 3–5 менеджерах, сбор замечаний | — |

После R7 — Windows (WASAPI loopback, общий `shared/`), затем macOS на Swift.

## Интерфейс

Выбран макет «Бабочка» (27 октября 2026, из пяти вариантов), 28 октября он
развит в макет 6 «Стеклянная волна». Макеты:
https://claude.ai/artifact/GLQ6PSRoc5V1crQ5CWN3Ch — артборды 4, 4a, 4b, 6.

Главная идея — окно прямо показывает раздельные каналы файла: **слева «Вы»
(канал L, микрофон, золотой), справа «Система» (канал R, клиент, голубой)**.
Цвета различаются и по светлоте, не только по оттенку. Текста минимум —
всё, что можно, показывает волна.

- Окно 380×520 (минимум 320×420), тянется за края. Сверху устройства: слева микрофон, справа вывод, между
  ними таймер с точкой (серая — не пишем, красная мигает — запись, жёлтая —
  пауза). Чип открывает список, первый пункт — «Системный (сейчас: Jabra)».
- В центре — волна: капсулы растут от центральной оси, микрофон влево,
  система вправо; уровень расходится от оси к краям, капсулы светятся и
  гаснут к краям. Фон за говорящей стороной подсвечивается.
- Устройства — просто текст со значком и шевроном, без рамок; щелчок открывает список.
- Внизу стеклянная капсула: до записи — «Настройки» (формат с явным
  «Сохранить», самопроверка записи обеих сторон с прослушиванием),
  бледная «Запись», «Папка записей»; в записи — «Пауза», яркий «Стоп» с
  кольцом, «Папка записей». Во время записи выбор устройства заблокирован.
- Плашка с текстом — только когда есть что сказать: «Пауза — не пишется»,
  предупреждение об устройстве (жёлтая), «Сохранено …», «Устройства
  недоступны». На паузе волна гаснет.
- Заголовок окна в цвет фона, как у EliteSIP: свой заголовок повторяет системный
  (кнопки, скругления), отличается только фоном. Значки — из набора EliteSIP.
- Иконка: корона и волна EliteRec на подложке как у EliteSIP; волна
  двухцветная, как в окне (`scripts/make-icon.py`).
- Тишина на одной из сторон дольше ~15 с во время записи — жёлтое
  предупреждение («Системы не слышно — проверьте вывод звука Zoom»).
- Трей: значок — волна из-под короны: двухцветная — не пишем, красная — идёт
  запись, жёлтая — пауза или предупреждение об устройстве. Крестик окна прячет
  его в трей. Меню: «Запись / Пауза / Стоп», «Открыть папку
  записей», «Открыть окно», «Выход».
- После «Стоп» — диалог «Название записи (необязательно)» → сохранение →
  открывается папка с выделенными файлами (для перетаскивания в Битрикс).
- Оформление — как EliteLinux: графит + золото.
